Jeff Elec

Plateforme de gestion de rebobinage de moteurs

Guide d'utilisation

Espace Technique • Administration • Facturation

1. Présentation

Jeff Elec est une application web qui suit chaque moteur confié à l'atelier, de la réception au test final, puis gère les clients, devis, factures et paiements (en Ariary, TVA 20 %).

EspacePour qui ?À quoi ça sert

AdministrationResponsable / patronSuperviser, valider, gérer clients, devis, factures, utilisateurs et paramètres.

Se connecter

  1. Ouvrez l'application : la page d'accueil propose Espace technique ou Administration.
  2. Choisissez votre espace, saisissez votre email et votre mot de passe.
  3. Cochez « Se souvenir de moi » pour rester connecté 30 jours (à éviter sur un appareil partagé).
Les comptes techniciens sont créés par l'administrateur. Un technicien doit être approuvé pour accéder à l'application.
Erreur « invalid-credential » : l'email ou le mot de passe est faux, ou le compte n'existe pas encore dans Firebase Authentication. Contactez l'administrateur.

2. Espace Technique

Menu : Tableau de bord, Nouveau moteur, Mon profil.

2.1 Enregistrer un nouveau moteur

  1. Cliquez sur Nouveau moteur.
  2. Renseignez le client, le type de moteur (monophasé, triphasé…), la plaque signalétique (puissance, tension, vitesse…) et la panne constatée.
  3. Validez : un numéro de dossier OR-AAAA-NNNN est attribué automatiquement.
  4. Les étapes de travail sont créées automatiquement selon le type de moteur.

2.2 Suivre les étapes

Ouvrez un moteur depuis le tableau de bord. Les étapes standard sont :

Diagnostic → Démontage → Débobinage → Nettoyage → Isolation → (étape spécifique monophasé/triphasé) → Bobinage → Connexions → Vernissage → Remontage → Test final.

  • Cochez chaque sous-étape terminée (ex. « Relever plaque », « Test Megger »).
  • Quand toutes les sous-étapes d'une étape sont cochées, l'application propose Demander la validation à l'administrateur.
  • Une étape validée est verrouillée : seul l'administrateur gère la suite.

2.3 Envoyer un rapport

Dans la fiche du moteur, ajoutez un rapport : texte, mesures et photos. L'administrateur est notifié (pastille sur « Rapports »).

2.4 Mon profil

Modifier votre nom, votre mot de passe ou votre email (une confirmation est demandée).

3.1 Valider une étape

  1. Cliquez sur la pastille de Moteurs.
  2. Ouvrez le moteur, contrôlez l'étape et les photos.
  3. Validez l'étape (ou renvoyez-la au technicien).

3.2 Gérer les utilisateurs

  1. Utilisateurs → Ajouter : nom, email, mot de passe initial, rôle.
  2. Le technicien se connecte avec ces identifiants et peut changer son mot de passe.
  3. Pour retirer un accès : supprimez le profil dans l'application, puis le compte dans la console Firebase (Authentication).

4. Clients, devis et factures

4.1 Créer un client

Clients → Nouveau : nom, téléphone, adresse, NIF/STAT si c'est une société.

4.2 Établir un devis

  1. Devis → Nouveau, choisissez le client.
  2. Ajoutez des lignes (depuis le catalogue ou en saisie libre) : quantité, prix en Ariary.
  3. La TVA 20 % et le total sont calculés automatiquement.
  4. Enregistrez, puis téléchargez le PDF pour l'envoyer au client.
  5. Passez le statut à Accepté ou Refusé selon la réponse.

4.3 Facturer et encaisser

  1. Factures → Nouvelle (ou depuis un devis accepté). Numéro automatique FA-AAAA-NNNN.
  2. Émettez la facture, puis enregistrez chaque paiement : espèces, virement, chèque, MVola, Orange Money ou Airtel Money.
  3. Le statut évolue : émise → partiellement payée → payée. Un avoir corrige une facture émise.
  4. Téléchargez le PDF de la facture.
Les montants sont des entiers en Ariary (MGA). Une facture émise ne se modifie plus : utilisez un avoir.

5. Installation initiale (administrateur)

  1. Console Firebase → Authentication → activer Email/Mot de passe.
  2. Créer le premier administrateur (script migrate-users.mjs --create-admin ou à la main : utilisateur Auth + document fortico_users/{UID} avec role="admin", approved=true).
  3. Déployer les règles : firebase deploy --only firestore:rules,storage.
  4. Renseigner Paramètres (raison sociale, NIF/STAT, logo, conditions) avant le premier devis.
